═══════════════════════════════════════════════════════════════
  STEP 1: UPLOAD TO YOUR CPANEL SERVER
═══════════════════════════════════════════════════════════════

1. Login to cPanel → File Manager
2. Navigate to public_html/ (or a subfolder like public_html/admin/)
3. Upload ALL files keeping this exact folder structure:

   public_html/
   ├── admin.html
   ├── index.html         ← Your existing public offers page
   └── api/
       ├── data.php
       └── store/         ← Must be writable!

═══════════════════════════════════════════════════════════════
  STEP 2: SET FOLDER PERMISSIONS
═══════════════════════════════════════════════════════════════

In cPanel File Manager:
  Right-click "api/store/" → Change Permissions → 755

Or via SSH:
  chmod 755 api/store/

The JSON files (offers.json, slider.json) will be created
automatically on first use.

═══════════════════════════════════════════════════════════════
  STEP 3: CHANGE YOUR PASSWORD (IMPORTANT!)
═══════════════════════════════════════════════════════════════

Open api/data.php in a text editor and change line 7:

  define('ADMIN_PASSWORD', 'YOUR_SECURE_PASSWORD_HERE');

Also change the secret on line 8:

  define('TOKEN_SECRET', 'any_random_string_here_xyz_123');

⚠️  DEFAULT PASSWORD IS "admin123" — CHANGE IT BEFORE GOING LIVE!

═══════════════════════════════════════════════════════════════
  STEP 4: OPEN THE ADMIN PANEL
═══════════════════════════════════════════════════════════════

Visit: https://yourdomain.com/admin.html
Login with your password.

Go to Settings → API Configuration and set:
  https://yourdomain.com/api/data.php

Click "Test Connection" to verify everything works.

═══════════════════════════════════════════════════════════════
  STEP 5: IMPORT YOUR OFFERS
═══════════════════════════════════════════════════════════════

Option A — Import from JSON file:
  1. Click Offers → Import
  2. Select a .json file (see sample-offers.json for format)
  3. Choose Append or Replace mode
  4. Click Import

Option B — Import from Excel:
  1. Click Offers → Import
  2. Select a .xlsx file
  3. First row must be headers: id, name, cat, payout, etc.
  4. Click Import

Option C — Drag & Drop:
  With the Offers panel open, drag a JSON or Excel file
  anywhere on the page to auto-open the import dialog!

Option D — Download Template:
  In the Import dialog, click "Download JSON Template" or
  "Download Excel Template" for pre-formatted starter files.

═══════════════════════════════════════════════════════════════
  STEP 6: EXPORT YOUR OFFERS
═══════════════════════════════════════════════════════════════

Click "Export" in the Offers panel to get:
  • JSON  — Machine-readable format for backup/migration
  • Excel — Spreadsheet with all columns formatted
  • PDF   — Professional dark-themed report for sharing

Exports respect active filters (e.g., export only SOI offers).

═══════════════════════════════════════════════════════════════
  STEP 7: CONNECT YOUR PUBLIC index.html
═══════════════════════════════════════════════════════════════

In your public index.html, fetch offers like this:

  fetch('api/data.php?resource=offers&action=list')
    .then(r => r.json())
    .then(json => {
      const offers = json.data; // Array of offer objects
      // Render your offers list here…
    });

For the hero slider:

  fetch('api/data.php?resource=slider&action=list')
    .then(r => r.json())
    .then(json => {
      const slides = json.data;
      // Render your slider here…
    });

The API is public (GET requests don't need auth).
Only write operations (POST/DELETE) require the admin token.
