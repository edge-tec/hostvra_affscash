🚀 Installation Guide

1Download the Package
Download all files from this admin panel package. Your file structure should be:
affscash-admin/ ├── admin.html ← This file (Admin Panel) ├── index.html ← Your public offers page ├── api/ │ ├── data.php ← PHP backend API │ └── store/ │ ├── offers.json ← Auto-created │ └── slider.json ← Auto-created └── INSTALL.txt
2Upload to cPanel via File Manager
✓Login to your cPanel → File Manager
✓Navigate to public_html/ (or a subfolder like public_html/admin/)
✓Upload all files keeping the folder structure intact
✓Make sure PHP 7.4+ is enabled on your hosting
3Set Folder Permissions
The api/store/ folder must be writable by PHP. In cPanel File Manager:
Right-click api/store/ → Permissions → set to 755
Or via SSH:
chmod 755 api/store/ touch api/store/offers.json api/store/slider.json chmod 644 api/store/offers.json api/store/slider.json
4Change Your Admin Password
Open api/data.php and change the password on line 7:
define('ADMIN_PASSWORD', 'YOUR_SECURE_PASSWORD_HERE');
Also change the token secret on line 8:
define('TOKEN_SECRET', 'any_random_long_string_here_xyz');
⚠️ Never use the default password on a live site!
5Configure API URL in Settings
Go to Settings → API Configuration and set your API URL:
https://yourdomain.com/api/data.php
Then click Test Connection to verify it works.

Default value api/data.php works if admin.html and the api/ folder are in the same directory.
6Import Your Offers (Optional)
You can bulk-import offers from JSON or Excel files. Go to Offers → Import.

JSON format — array of offer objects:
[ { "id": 100, "name": "My Offer Name", "cat": "soi", "payout": 3.50, "payoutDisplay": "$3.50", "countries": "US GB AU", "link": "https://yourlink.com", "badges": "hot,new" } ]
Excel format — first row must be headers: id, name, cat, payout, payoutDisplay, countries, link, badges

You can also drop a JSON or Excel file anywhere on the Offers page and it will auto-import!
7Connect Your Public index.html
Your public-facing index.html should fetch offers from the same API:
// In your index.html JavaScript: fetch('api/data.php?resource=offers&action=list') .then(r => r.json()) .then(json => { const offers = json.data; // Array of offer objects // Render your offers here… });
For the slider:
fetch('api/data.php?resource=slider&action=list') .then(r => r.json()) .then(json => { const slides = json.data; // Render your slider here… });
